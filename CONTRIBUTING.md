# Contributing

This is a prompt and documentation library. There is no application to install or server to run.

## Suggest a change

Open an [issue](https://github.com/canmils/ai-prompts-for-game-production/issues) explaining the production task, who needs it and what the existing template misses. Include a small fictional input and expected result. For a model-output issue, add the provider/model, date, actual output and the source fact it failed to preserve.

Do not include credentials, personal information or private employer material.

## Submit a pull request

1. Fork the repository and create a branch for one focused change.
2. Edit the relevant template and document its required inputs.
3. Include a fictional example and criteria for a useful result.
4. Label examples as human-authored or model-generated. Name model/date for generated examples when known.
5. Review the draft for invented facts, owners, dates, requirements and approvals. Preserve uncertainty explicitly.
6. Check Markdown rendering, links and placeholders.
7. Open a pull request explaining the problem, changes and verification limits.

No paid model call is required to contribute. If you test in an AI tool, use your own permitted account and material; a single successful response is an example, not a benchmark.

Keep claims proportional to evidence. A template can help review requirements; it cannot verify current law, certify a game or authorise a release. Preserve attribution and licences for any material you incorporate.
